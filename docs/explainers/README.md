# Explainers

Explainers go deep on one topic: how it works in the real world, why, and how the island models it.

They are written so someone who never plays the game can learn from them. Each ends with what the game does and where it differs from reality. The [field guide](../field-guide/README.md) is for quick look-ups of a species or habitat; explainers are for understanding a process or a place in depth. See the [knowledge framework](../knowledge-framework.md) for how the two fit together.
