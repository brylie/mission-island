# Second shift · A return load from Seabrook

**Design question.** After seeing two coins land in the crew bank, can both players name something they want to do together tomorrow? Ask this at the first hand-in, while two starter crates are still owed. Record their answers before describing this proposal. [First-payday playtest](../playtests/starter-island-first-payout.md)

**Proposed experiment.** Give the crew a reason to visit a familiar place again. The Seabrook shopkeeper has an empty produce crate to send back to Harbor Depot. A player who remembers getting paid to bring something *here* can now work out who needs the return journey. Try one crate, one trip and a provisional two-coin payment. This offer is a candidate for the milestone. The starter delivery, lookout fire and repeatable board orders are playable today. [Current order rules](../mechanics/crew-orders.md)

## What the crew experiences

| When | What happens in the trial |
| --- | --- |
| At the first payday | Both screens still show the original starter delivery, its remaining crates and the new balance. Ask what each player expects after finishing the shift. |
| At Seabrook after finishing the lookout fire | With the shared order slot free, either player can inspect a return crate by the market. The tag names Harbor Depot. The offer shows destination and pay before acceptance. Walking away leaves it available for later. |
| Someone accepts | The crew sees one active order and one tagged crate at the market. The partner can read the destination from the truck. If a partner takes a board job at the same time, the host grants the slot to the first valid request and tells both players which job they took. |
| On the way back | One person can carry, load, drive, unload and hand in. A pair can split loading and positioning the truck, then swap the wheel for the return run. Try this with a player who prefers handling cargo. |
| At Harbor Depot | The receiving bay matches the tag. Either player can hand in the crate. Both see the order clear and the bank rise by two coins once. The job board becomes available again. |

For this trial, offer the return load once per save. Keep the existing four-board-order readiness count and career qualification rules intact. A crew with an older eligible save can find the offer when its active slot next clears. Reopening the game restores an accepted return load, its crate and destination, or the completed state. Losing cargo needs a recovery path at the pickup so the crew can finish the job with exactly one deliverable crate.

## Acceptance playtest

1. Start at the first payday. Ask both players what they think comes next, then let them finish the starter shift. Record how they find work on their next visit to Seabrook.
2. Try inspecting the offer during a board order, leaving it for later, and accepting it together. Verify there is one active order, one crate and a useful task for the passenger. Repeat the journey solo from an equivalent eligible save.
3. Disconnect the driver after loading. Restart the host, rejoin, and finish with the other player. Try the hand-in twice and revisit the pickup. Compare the shared balance, completed state and readiness count on both screens.
4. Ask each player who needed the trip and whether they would have returned without the prompt. Record where they waited for each other and whether that wait felt like teamwork. If they remember the route and choose it freely, try another resident’s return load. If they only follow the marker or the trip is mostly waiting, revise the offer or roles before adding more routes.
